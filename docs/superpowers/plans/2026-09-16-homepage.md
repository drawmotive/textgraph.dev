# TextGraph homepage implementation plan

**Goal:** Implement the approved homepage story: understand the idea, learn the
approach, see useful results, and open the exact example in the playground.

**Design:** A restrained, diagram-led page with a source/output hero, a progressive
connections/labels/groups demonstration, a before/after cache example, three
real-use examples, working integrations, and concise availability answers.
All diagram previews come from the published SDK; no invented output or planned
features presented as available. Inline freeform editing remains in the playground.

**Architecture:** A focused homepage Vue component uses a reusable source/output
figure. A shared example catalog owns DSL, accessible descriptions, and IDs used
by source links and analytics. A build-time script renders PNGs and their manifest;
the homepage never starts the WASM renderer. VitePress retains navigation, docs,
and search. Existing analytics reports the new homepage version and example IDs.

**Worktree:** Reuse this session's textgraph-home-analytics branch/worktree. Commit
verified changes there; do not merge, push, or deploy without a new instruction.
