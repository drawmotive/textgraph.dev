# Security reporting

This policy covers the public documentation site, playground, embedded
examples and client-side integrations. Include the affected URL, deployed
version if known, browser/OS, a minimal reproduction and expected impact.
Remove secrets and unrelated private diagram source from reports.

If GitHub private vulnerability reporting is available for this repository,
use [Report a vulnerability](https://github.com/drawmotive/textgraph.dev/security/advisories/new).
Availability depends on repository settings; this document does not assert
that the feature is enabled.

If that option is unavailable, contact project maintainer
[devmasonz](https://github.com/devmasonz) to request a private reporting
channel; do not post exploit details publicly. The maintainer profile is an
interim contact route. A dedicated private reporting contact has not yet
been confirmed.

Use the [shared issue tracker](https://github.com/drawmotive/textgraph/issues)
for ordinary documentation bugs and support questions without sensitive details.
