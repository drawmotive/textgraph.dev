1. Install and copy browser assets

npm install @drawmotive/textgraph@0.2.1
npx textgraph-copy-assets public/textgraph/wasm

Use a JavaScript bundler such as Vite. Serve the public directory over HTTPS or localhost.

This example is plain HTML and JavaScript. View its JavaScript or browse the complete source ↗.

2. Render source into an image

import { initializeTextGraph }
  from "@drawmotive/textgraph/browser";

const graph = await initializeTextGraph({
  resolveAsset: asset =>
    new URL(`/textgraph/${asset.path}`, location.origin),
});
const result = await graph.renderPng("A -> B", {
  encoding: "base64",
});
if (result.success) {
  document.querySelector("img").src =
    `data:image/png;base64,${result.png}`;
}
await graph.dispose();
